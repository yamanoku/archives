# [archives.yamanoku.net](https://archives.yamanoku.net/)

[yamanoku](https://github.com/yamanoku) archive contents. (Japanese text only)

Astro から [Ox Content](https://github.com/ubugeeei-prod/ox-content) へ移行した静的サイトです。記事本文は `src/archives` の Markdown で管理しています。

## Build Setup

```bash
# install dependencies
$ npm ci

# serve with hot reload at localhost:5173
$ npm run dev

# generate static project
$ npm run build
```

Node.js 24 以上が必要です。
